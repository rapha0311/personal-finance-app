### 💰 Personal Finance App — Full Stack

Aplicação web para controle financeiro pessoal, desenvolvida com React,
JavaScript, Tailwind CSS, FastAPI, Python e SQLite.

O projeto está sendo desenvolvido com foco em organização de código,
separação de responsabilidades e construção de uma aplicação Full Stack
com comunicação entre frontend e backend.

**Funcionalidades implementadas até o momento:**
- Cadastro e gerenciamento de categorias
- Cadastro de receitas e despesas
- Edição e exclusão de transações
- Consulta de transações
- Controle de metas financeiras
- Criação, atualização e exclusão de metas
- Acompanhamento do progresso das metas
- Dashboard financeiro
- Cálculo de receitas, despesas e saldo
- Transações recorrentes
- API REST desenvolvida com FastAPI
- Persistência de dados utilizando SQLite e SQLAlchemy
- Estrutura backend organizada em Routes, Services, Repositories e Models
- Integração do frontend React com a API

**Tecnologias:**
React • JavaScript • Tailwind CSS • Python • FastAPI • SQLAlchemy • SQLite

**Status:** 🚧 Em desenvolvimento
